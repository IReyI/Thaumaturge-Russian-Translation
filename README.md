# Thaumaturge — Russian Translation 🇷🇺

**Неофициальный русский перевод мода Thaumaturge для Minecraft.**

Этот ресурс-пак добавляет русскую локализацию для [Thaumaturge](https://www.curseforge.com/minecraft/mc-mods/thaumaturge) — магического мода, вдохновлённого Thaumcraft.

Цель проекта — сделать игровые механики, предметы, описания и интерфейс мода доступнее для русскоязычных игроков.

## ✨ Особенности

- 🇷🇺 Русская локализация игрового контента.
- 📖 Перевод названий, описаний и подсказок.
- 🔮 Локализация терминологии, связанной с магией и исследованиями.
- 🛠️ Постепенное расширение перевода и исправление неточностей.

Полнота перевода зависит от текущей версии ресурс-пака.

## 🎮 Совместимость

- **Minecraft:** версия, указанная в выбранном релизе.
- **Mod Loader:** NeoForge.
- **Основной мод:** [Thaumaturge](https://www.curseforge.com/minecraft/mc-mods/thaumaturge).
- **Тип локализации:** ресурс-пак.

Используй версию русификатора, соответствующую версии Minecraft и Thaumaturge, для которой он был подготовлен.

## 📥 Установка

1. Скачай архив русификатора из раздела [Releases](../../releases).
2. Открой папку `resourcepacks` в каталоге Minecraft.
3. Помести ZIP-архив русификатора в эту папку. **Не распаковывай архив**, если в инструкции к релизу не указано иное.
4. Запусти Minecraft.
5. Перейди в **Настройки → Наборы ресурсов**.
6. Включи русификатор. Если используются другие ресурс-паки, проверь их порядок приоритетов.
7. Открой **Настройки → Язык** и выбери **Русский**.

После включения ресурс-пака переведённые строки должны отображаться на русском языке.

## 🔧 Решение проблем

**Перевод не отображается**

- Убедись, что выбран русский язык Minecraft.
- Проверь, что ресурс-пак включён.
- Проверь порядок ресурс-паков: другой пак с переводами может переопределять те же строки.
- Убедись, что архив содержит папку `assets` и корректный файл `pack.mcmeta`.

**Часть текста осталась на английском**

Это может означать, что соответствующие строки ещё не переведены или что их идентификаторы изменились в новой версии мода.

**Русификатор не появляется в списке**

Проверь структуру ZIP-архива. Файл `pack.mcmeta` должен находиться в корне ресурс-пака, а не во вложенной папке.

Если проблема сохраняется, создай сообщение в [Issues](../../issues) и укажи версии Minecraft, NeoForge и Thaumaturge.
